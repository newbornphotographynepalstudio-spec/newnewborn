# Newborn Photography Nepal — by Navin

Production website for Newborn Photography Nepal (Kathmandu Valley, Nepal).

This is the Phase 1 project foundation. See:

- [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) — the full architecture (routes, Firestore schema, roles, SEO, image pipeline, brand direction).
- [`docs/SETUP.md`](docs/SETUP.md) — local development, environment variables, Firebase setup, build/lint/typecheck, deployment.

## Quick start

```bash
npm install
cp .env.example .env.local   # fill in real values, see docs/SETUP.md
npm run dev
```
